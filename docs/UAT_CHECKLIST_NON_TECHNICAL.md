# UAT Checklist (Non-Technical)

Use this checklist before go-live.

## A. Basic Flow
- [ ] I created an invoice in QuickBooks.
- [ ] The invoice appeared in PandaDoc without uploading a PDF manually.
- [ ] Payer information was correct.
- [ ] Amount and due date were correct.
- [ ] The invoice status changed to **Sent**.

## B. Status Tracking
- [ ] I can see if invoice is Sent / Opened / Paid / Failed.
- [ ] Status updates happen within expected time.
- [ ] I can identify which invoice failed.

## C. Exception Handling
- [ ] I know what to do if status is **Failed**.
- [ ] I can correct invoice data in QuickBooks.
- [ ] I can trigger resend (or confirm automatic retry).
- [ ] Manual fallback process is documented and clear.

## D. Operations Readiness
- [ ] Team knows where to check daily invoice sync status.
- [ ] Team has an owner for first-line incident response.
- [ ] Team has contacts for technical escalation.
